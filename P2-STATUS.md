## Что находится в этой ветке

- **M08:** отдельная сохраняемая очередь Ask, pending/answered/failed, страницы
  ожидающих вопросов, версия ответа, идемпотентная квитанция. Приватность и
  отсутствие сюжетных изменений сохранены. Новые human-mode Ask возвращают 202.
- **M09:** общий runner передаёт `--experimental-vm-modules` дочерним процессам;
  ошибка либо сигнал дочернего процесса остаётся ошибкой, не skip.
- **M11, частично:** сохраняемые минутные квоты Ask/действий/whispers, общий
  пользовательский и кампанийный лимиты; ограничение количества pending Ask.
  Это не смысловой фильтр и не бюджет затрат провайдера.
- **M12:** все три входных канала проверяют `requireVoice`. Заглушённый участник
  не может послать whisper, но сохраняет чтение собственной истории.
- **M13:** бюджет данных read, страницы одного hash-consistent снимка,
  явная live-проекция и отказ вместо обрезания слишком большого значения.
  Поля опубликованы через обязательный MCP preload. Маленький `connect` сохранил
  прежнюю форму; paging включается явно, а не ломает старых клиентов молча.
- **M14, частично:** обновлён narrator skill и написан
  [технический сценарий первого сеанса](docs/external-narrator-first-session.md).
  Его выполнение с чистой установки ещё не подтверждено.

## Что намеренно НЕ объявлено завершённым

**M10 не включён:** запись подготовленных файлов отдельного narrator-runtime
получила отказ инструмента публикации. В эту ветку не добавлены его Dockerfile,
host loop, checkpoint/recovery-код или lifecycle hooks. Не запускайте здесь
несуществующий `narrator/run.mjs` и не считайте managed host установленным.
Блокированный запрос не переупаковывался в иной способ публикации.

Не опубликованы и не проверены runtime-dependent части M11: смысловые входной
и выходной gates, суточная стоимость, поведение живой модели. Для M13 остаётся
проверка длительного сеанса и host memory/compaction; бюджет страниц сам по себе
не реализует память агента. Для M14 остаётся фактическая приёмка установки.
