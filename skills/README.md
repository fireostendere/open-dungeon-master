# Skills

The project skill source for ODM and D&D lives in `.opencode/skills/`, where
custom OpenCode loads each subdirectory's `SKILL.md`. This top-level folder is a
pointer for people browsing the repository, not a second copy of the skills.

See [the skill catalog](../docs/agent-skills.md) for descriptions and safe
loading order, or browse the [runtime skill files](../.opencode/skills/).
