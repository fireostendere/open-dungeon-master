# NPC и фракции

Если доступен репозиторий, прочитайте [общий контракт](../../../docs/agent-skills.md#общий-контракт-и-границы) и
связанный черновик из [dnd-campaign](../dnd-campaign/SKILL.md). Навык не требует ODM.

## Вход

Ситуация кампании, нужная роль, отношения с PC и допустимые спойлеры.
Уточните аудиторию: текст для игроков, заметки DM или раздельные версии.

## Построение

1. Дайте NPC желание, страх, ресурс, цену помощи и заметную манеру речи; избегайте акцента как шутки.
2. Фракции получают цель, методы, активы, уязвимость, отношения и план действий без PC.
3. У каждого секрета добавьте носителя, след и способ раскрытия; не делайте один hidden check воротами.
4. Свяжите отношения стрелками «хочет/должен/боится/использует» и отметьте конфликт интересов.
5. Для возвращающихся NPC ведите краткую таблицу: известное PC, истина для DM, изменения после событий.
6. Последствия должны следовать из ресурсов и мотива, а не защищать план автора.
7. Не публикуйте тайный список NPC в общем чате: владелец/администратор может быть игроком;
   заголовок Markdown «только для DM» не защищает доступ.

## Шаблон

```text
Имя/роль/voice: … | Цель/страх: … | Ресурс/цена: …
Связи: … | Secret → clue: … | Clock/следующее действие: …
```

Готово, когда NPC может реагировать на выборы PC без знания «правильного» сюжета.
