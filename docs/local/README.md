# Исторические заметки локальной установки

Материалы этой папки относятся к отдельным машинам, старым коммитам и прошлым
прогонам. Их абсолютные пути, версии, PASS/BLOCKED-отчёты нельзя автоматически
переносить на новую установку.

Актуальные инструкции: [установка](../installation.md), [эксплуатация](../operations.md),
[бэкапы](../backups.md), [проверки](../deployment-testing.md).
Старые файлы сохранены как история, не удалены и не выданы за новые результаты.
