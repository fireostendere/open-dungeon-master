# Подключения LLM уже в main

Старая ветка `astra/browser-auth-review` была включена в main. Актуальная инструкция
перенесена в [llm-wizard.md](llm-wizard.md); версия установки и контейнерный запуск —
в [installation.md](installation.md). Этот адрес оставлен для старых ссылок.

Для ручного запуска из исходников сохраняются `npm ci`, `npm run build`,
`npm run start:lan` и `npm run auth -- …`. В управляемом Docker-развёртывании
используйте `odmctl auth …`: официальный Codex уже включён в image.

Граница остаётся прежней: автоматические проверки реализации не заменяют
подтверждение входа владельцем личного ChatGPT-аккаунта. Gemini/Qwen OAuth подписок
не заявлены; используются их API-ключи или локальный runtime.
