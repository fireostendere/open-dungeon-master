## Integrated features and fixes

Player Say/Do/OOC styles have distinct text/icon cues plus sky/amber/muted dashed
presentation, with RU/EN/PL labels. Parsing is display-only; stored actions and
transcripts are unchanged. DM/system/blocked-message/report/retry/media behavior
continues to use the reviewed main implementation.

`odm_narrator` adds `answer_ask`; a fourth resource, `odm://narrator/playbook`,
explains the real rules-engine, read/write and privacy protocol. New operations
retain the cancellation wrapper and mandatory preload checks.

Narrator read and `campaigns.events` filter OOC additions/edits. Cursor progression
uses the unfiltered page. `campaigns.events` additionally returns cursor,
nextCursor, currentSeq and hasMore so an empty OOC-only page cannot cause a loop.
OOC remains in player chat and persisted messages; filtering is not deletion.

Ask updates require the question's campaign ID in both SQL write and read.
Cross-campaign question UUIDs return not found. Private submissions and answers
never enter shared persisted events. Contentless private notifications target
identified subscribers; table-visible notifications remain contentless broadcasts.
Ask has no story sequence/floor advancement or automatic DM turn. Human-mode
submission keeps the existing answered/failed DB contract with a localized
acknowledgement, not an invented pending-schema migration. The external reader
must inspect asks even when its story cursor has not changed. The latest-20 Ask
view is not a complete unbounded work queue.

The app-port `/mcp` bridge accepts the caller's bearer and forwards it unchanged
to the server-configured sidecar. It does not grant the application's own token.
Cookies/Host/forwarding claims cannot choose the upstream. Redirects are refused,
uploads are bounded to 1 MiB, hop/encoded/cookie response headers are stripped,
and the response body remains streaming. `ODM_MCP_PROXY_URL` is a trusted server
setting (default `http://mcp:3006/mcp`); native non-Docker deployments must point it
to their actual sidecar. Managed Caddy normally routes directly to MCP instead.
Use HTTPS/private tunneling; this route does not make plaintext bearer use safe.

Agent guides and the narrator skill are reconciled with the implementation. They
no longer assume an extra repository subdirectory, fixed account UUIDs, automatic
write replay, guaranteed host watch scripts or production authorization from a
code-change request.
