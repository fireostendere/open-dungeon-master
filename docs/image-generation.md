# Карты, портреты и изображения

Графические возможности приложения сохраняются: static scene art, портреты и
карты с отдельными токенами. Выбор текстовой модели не заменяет image backend.

Управляемая установка подключает существующую ComfyUI через `--comfy-url` /
`-ComfyUrl`, например `http://host.docker.internal:8188`, либо облачный image API
через существующий раздел админки. Для удалённой ComfyUI используйте её реальный
доступный адрес и защищённую сеть. Не открывайте её без авторизации в интернет.

Установщик не меняет GPU-драйверы и не обещает автоматическую CUDA/ROCm поддержку.
Image-модели и ComfyUI workflow должны соответствовать выбранному серверу.

После подключения выполните настоящую генерацию портрета и карты и проверьте,

Сгенерированные и загруженные файлы находятся в `state/generated`, `state/uploads`
и при необходимости `state/audio`; они включены в общий согласованный backup
с SQLite. Веса и кэш внешней ComfyUI туда не входят — обслуживаются отдельно.

Подробности workflow и image-провайдеров: [исходная техническая справка](image-generation-reference.md).
