# Текстовые backend

ODM больше не запускает текстовый backend на сервере. Модель выбирается и
вызывается внешним narrator-host; настройка ODM описана в
[external-narrator.md](external-narrator.md).

[Upstream-справка](text-backends-reference.md) сохранена только как исторический
материал и не описывает действующий runtime этого форка.
