# Проверка развёртывания

Быстрые тесты эксплуатации не требуют модели, аккаунтов, GPU или сетевых запросов:

```bash
python3 -m unittest discover -s tests/deploy -v
bash install-server.sh --plan
```

На Windows CI дополнительно разбирает PowerShell AST установщика и запускает
`-Plan`, проверяя отсутствие изменений файловой системы. Обработка ошибок нативных
команд проверяется отдельно в PowerShell 7 и Windows PowerShell 5.1.

Отдельные Linux jobs на Ubuntu 22.04 и 24.04 запускают **standalone installer**
на точном коммите: устанавливают зависимости, собирают Docker image этого форка,
создают шифрованную БД и администратора, запускают приложение. Затем проверяются
реальные restic backup/restore, возвращение HP/сюжета/сообщений/media, ошибочный
новый контейнер с откатом, журнал прерванного перехода и restart после аварийного
завершения процесса тестового контейнера. На время live-прогона захватывается
операционная блокировка: watchdog не может незаметно исправить ошибку проверяемого
сценария. Второй restic repository используется для проверки копирования и restore.
Контроллер поддерживает обе команды copy: старую --repo2 и новую --from-repo,
не меняя местами источник и назначение и не заменяя системный пакет restic.

CI не выдаёт Docker-симуляцию из unit tests за интеграционную проверку: live jobs
используют настоящие Docker, драйвер шифрованной SQLite и restic.
Но они **не** подтверждают ваш DNS, ваш VPS, физическую перезагрузку Windows,
GPU-ускорение или качество конкретного LLM. В live jobs явно отключены внешние
скачивания Open5e/embedding assets и не выполняются платные model requests.
Проверяйте итог конкретного коммита: наличие workflow не означает, что он прошёл.

Существующие provider-тесты, production build, полный набор игровых тестов и
браузерный сценарий админки остаются отдельным workflow. Его успешность не является
полным аудитом всех сторонних зависимостей.

Артефакты `deployment-recovery-evidence-ubuntu-*` содержат машинный итог live-checks
и санитизированный health JSON. Ключи, admin.json и recovery kit в артефакты не входят.
